# 录入错题

目标：用户给的是**原始材料**，交出去的是**库里的一条条错题**。不要只把材料复述一遍。

## 0. 先判断材料形态

| 用户给的是 | 怎么走 |
| --- | --- |
| 一段文字（题干+答案） | 直接进第 1 步 |
| 整张卷子 / 多道题 | 进第 1 步，按题切开，走批量 |
| 一张或几张图片 | 先看能不能读图（见第 4 步），读不出就走「图片入库」 |

**读不了图就直说，不要猜题干。** 你可以先把图片当附件存进库（`mb_add` 的 `images`），题干留空，然后请用户补一句文字题干。猜出来的题干比空题干更糟——它会被当成真的记住。

## 1. 抽字段

每道题按这套字段抽，抽不到就留空，**不要编**：

| 字段 | 说明 |
| --- | --- |
| `question` | 题干。**必填**（只发图时除外）。保留原式，数学式子用 `$...$` |
| `my_answer` | 学生当时写的错答。材料里没有就留空 |
| `answer` | 正确答案。**没给就留空**，不要自己算一遍填进去 |
| `analysis` | 解析 / 解题步骤。没给就留空 |
| `error_reason` | 错因的一句话描述 |
| `mistake_type` | 只能取：概念不清 / 计算失误 / 审题错误 / 方法不会 / 粗心 / 其他 |
| `subject` | 学科，如 高数 / 英语 |
| `knowledge` | 知识点。有层级就写成 `父/子`，如 `函数/单调性` |
| `source` | 来源，如 作业 / 周测 / 期中 |
| `tags` | 逗号分隔，用来做临时标记，不要拿它替代知识点 |
| `difficulty` | 1-5，估不出来就别填（默认 3） |

三条硬规矩：

1. **答案和解析只从材料里取。** 材料没写答案，就留空并明确告诉用户「答案我留空了，你自己补一句更准」。自己算出来的答案一旦错了，会把错误固化进库。
2. **知识点优先复用库里已有的写法。** 拿不准就先 `mb_search(knowledge="关键词")` 看有没有同类题；同义不同写法（`函数 单调性` vs `函数/单调性`）会分裂成两个知识点，事后要靠合并收拾。
3. **错因分类只能取那六项。** 材料里写「马虎」就归到「粗心」，「不会做」归到「方法不会」，但不要新造分类。

## 2. 单题入库

```
mb_add(question=..., my_answer=..., answer=..., analysis=...,
       subject=..., knowledge=..., mistake_type=..., source=..., tags=..., difficulty=...)
```

有图片就带 `images`：

```
mb_add(question=..., images=[{ path: "C:/.../q.png", field: "question" }])
```

`field` 取 `question` / `wrong` / `answer` / `analysis`，一张题最多 6 张。

## 3. 多题批量

两道以上就走批量，别连着调十次 `mb_add`。

**第一步，预览：**

```text
mb_batch(text="题目: ...\n我的答案: ...\n正确答案: ...\n知识点: ...\n---\n题目: ...", preview=true)
```

`preview` 默认就是 `true`，只回显「共几道 + 各道标题」，不写库。

**第二步，核对。** 把切出来的标题念给用户看，特别是：

- 题数对不对（切多了 / 切少了）
- 有没有「没识别到题干」的条目
- 知识点和错因分类有没有落对

**第三步，确认后再真入库：** 同样的内容再调一次，带 `preview: false`。

用户说「就这些，录吧」也算确认；用户没说就先把预览给他看，不要抢跑。

## 4. 图片入库

按能力分两条路：

- **模型能读图**：先读出题干与答案 → 按第 1 步抽字段 → 走 `mb_add` 或 `mb_batch`。
- **模型读不了图**（会报不支持图片输入）：把图片作为附件存进库，题干留空，然后请用户补文字。`mb_add` 允许「只有图没有题干」。

一张图里有多道题时，按题切分后每道单独录，图片可以共用（每题都带同一个 `path`）。

## 5. 收尾

录完报三件事：

1. 入了哪几道（题号）
2. 哪些字段是空的（尤其是答案 / 解析 / 知识点）
3. 下一步建议

> 比如：「入了 #18 #19 #20。其中 #19 没给答案，#20 没填知识点，你补一下我再更新。要不要现在就用 `mb_brief` 看今天该练哪几道？」

不要录完就沉默，也不要顺手把答案编上。

## 边界

- 用户只给题干、说「先记下来」→ 就只录题干，别追问一长串字段。
- 用户贴的是**别人的题**（不是自己做错的）→ 提醒一句：错题本是记自己的错，纯题库放进来会稀释复习计划。
- 材料里同一道题出现两次 → 交给 `mb_batch` 判重（3 秒内同题干会被拦），不要手工去重。
- 不要在录入阶段讲题。要讲就另起复习模式（`mb_get` + `mb_review`）。
- 录完不要自作主张设 `status` 或 `next_review_at`，交给 FSRS。
