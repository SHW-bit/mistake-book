# 复习闭环

一次只走一道题。四步，缺一步就不算复习完。

## 1. 取题

调 `mb_due`（默认未来 7 天，`limit` 控制列几道）。

- 用户说「我哪里弱」「哪科最差」→ 改调 `mb_stats` 的 `view: 'mastery'`，先给薄弱知识点，再取题。
- 用户点名某科/某知识点 → 调 `mb_search`（`subject` / `knowledge` / `tag`），别硬用到期列表。
- 没有到期题就直说，不要编题凑数。

拿到题号后用 `mb_get` 读全文——**必须先看正确答案与解析**，否则判分没有依据。

## 2. 让学生先讲

把题干原样给出，**不要**同时给答案。问一句：「这题你当时怎么想的？」

- 学生答对思路 → 直接进第 3 步。
- 学生答错或卡住 → 先指出他错在哪一步（用 `my_answer` 和 `error_reason` 对照），再进第 3 步。

不要在学生没开口前就讲解题步骤——那样复习就变成了看答案。

## 3. 出变式题

在原题基础上换数字、换条件、换问法，**保持同一个知识点**。一题即可，不要一次给三道。

- 变式题由你现场出，不写进错题本（它还不是学生的错题）。
- 出完等学生作答。答完再判。

## 4. 判分并回写

按学生对**变式题**的表现给评分，调 `mb_review`：

| 表现 | rating |
| --- | --- |
| 完全不会 / 又错了同一处 | `again` |
| 想起来一半，仍需提示 | `hard` |
| 独立做对 | `good` |
| 秒答且能说清为什么 | `easy` |

评分是给**原题**的（变式题只用来测），所以 `id` 用第 1 步拿到的题号。

回写后念一句下次复习时间（`mb_review` 会返回），然后问「继续下一道？」。

## 学生新错的题

复习中如果学生暴露了**另一道**题的错误，用 `mb_add` 记下来：

```
mb_add(question=..., my_answer=..., answer=..., analysis=...,
       subject=..., knowledge=..., mistake_type=..., source='复习')
```

`mistake_type` 只能取：概念不清 / 计算失误 / 审题错误 / 方法不会 / 粗心 / 其他。

## 边界

- 一次一轮，不要连着出五道题。
- 判分要严：`good` 是「独立做对」，不是「听懂了解法」。
- 学生要求直接看答案时给，但看完仍要 `mb_review`（按 `again` 或 `hard` 记），不要跳过回写——跳过等于这道题白复习。
