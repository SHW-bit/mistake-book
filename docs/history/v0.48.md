# 5.45 删掉内置来源：候选只来自数据（v0.48）

> 本文件是[错题本 README](../../README.md)的拆分文档。含 5.45 节。上一版见 [v0.47.md](v0.47.md)。

## 5.45.1 问题：8 个内置值永远删不掉

用户的原话很短：「来源内置没啥用」。

v0.43 已经把来源候选从「常量」改成了「数据」—— 下拉按题量排序、0 题的内置值不显示。但那次只做了**显示层的隐藏**，常量 `SOURCE_HINTS` 还在，`_field_facets()` 每次都把 8 个内置值（作业 / 练习册 / 周测 / 月考 / 期中 / 期末 / 模拟考 / 其他）补进 `source_facets`，带 `system: true`、`count: 0`。

后果集中在「词表整理」面板里：

| # | 现象 | 根因 |
|---|---|---|
| 1 | 面板里永远有 8 行「未使用 · 内置」 | facets 里带着 `count=0` 的内置项 |
| 2 | 删了下次请求又回来 | 删除只改数据，`_field_facets()` 又把常量并回去 |
| 3 | 一个纯自用的本地错题本，来源本该自己定 | 内置列表是替新用户预设的，但代价是所有人都在忍受它 |

## 5.45.2 改了什么

| 位置 | 改动 |
|---|---|
| `app.py` | 删掉常量 `SOURCE_HINTS` |
| `app.py` `_field_facets()` | `source` 分支不再拼 `used` / `unused`，不再输出 `system` 字段，直接返回 `[{name, count}]`；排序仍是「题量降序 → 最近用过 → 名字」 |
| `app.py` `meta()` | `sources` 直接取 facets 的名字（不再需要过滤 `count>0`，因为已经没有 0 项） |
| `dsh-plugin/lib/client.js` `sourcePlaceholder` | 固定返回 `如：期中 / 月考`，不再从「未使用的内置值」拼 |
| `dsh-plugin/lib/client.js` `VocabPanel` | 行渲染去掉「未使用」徽标与「内置」标记，统一显示 `N 题` |

一处顺带的正向效果：`source_facets` 从「两组」变成「一组」，前端判断少了一个分支。

## 5.45.3 为什么直接删，而不是做成「可配置的内置列表」

考虑过把 8 个值挪到 `settings` 表里做成可增删的种子列表。没做：

- **它解决的不是真问题** —— 内置值唯一的用处是「新用户第一次录入时不知道填什么」。这件事用 placeholder（`如：期中 / 月考`）就够了，不需要真数据。
- **多一份要维护的状态** —— 种子列表进了库就要考虑：删了种子已有的题怎么办、导入导出要不要带、备份恢复要不要合并。为一个提示文案付这些成本不值。
- **空库不是死路** —— 来源是普通文本框，想填什么填什么；填过一次它就变成候选。词表本来就是「用出来的」。
