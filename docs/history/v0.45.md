# 5.42 字段旁加「管理」：删下拉候选不用再翻菜单（v0.45）

> 本文件是[错题本 README](../../README.md)的拆分文档。含 5.42 节。上一版见 [v0.44.md](v0.44.md)。

## 5.42.1 问题：v0.44 的 × 答错了问题

用户原话是「来源输入框，如果我不想要标签或点错了想删了怎么办」。v0.44 给四个自由文本字段加了 ×，但那**只清这一次输入**，不碰下拉候选。用户随后指出：要删的是下拉里的历史值（`高数`、`111` 这类），× 管不着。

下拉候选不是浏览器里存的标签，是**从题库数据聚合出来的**：`/api/meta` 返回 `subject_facets` / `source_facets` / `tag_facets` / `knowledge`。所以只有把用到这个词的题改掉（或合并到别的词），候选才会消失。`<datalist>` 本身也不支持删条目。

而当时的唯一入口是「更多 ▾」→「词表整理」，或者学习页最底部的折叠块 —— 用户在录入弹窗里根本想不到去那儿。

## 5.42.2 改了什么

| 位置 | 改动 |
|---|---|
| `dsh-plugin/lib/client.js` | 新增 `fieldLabel(text, kind)`：字段标签变成 `h('span.mb-flabel', ...)`，文字后面挂一个「管理」小按钮，点了 `setVocabKind(kind)` |
| 同上 | 学科 / 知识点 / 来源 / 标签 四处的 `h('span', null, '学科')` 换成 `fieldLabel(...)`，档位分别是 `subject` / `knowledge` / `source` / `tag` |
| 同上 | `ItemForm` 末尾按 `vocabKind` 挂 `VocabDialog`，关闭时清空并调 `props.onMetaChanged()` 重拉 meta，下拉立刻跟上 |
| 同上 | `VocabPanel(props)` 接 `initialKind`，`useState((props && props.initialKind) || 'source')` —— 同一块面板，两处入口 |
| 同上 | `DetailPane` 与 App 两处把 `refreshMeta` 透传下去 |
| 同上 | CSS 三条：`.mb-field>span.mb-flabel` / `.mb-manage` / `.mb-manage:hover` |

## 5.42.3 两个语义分清了

| 想删什么 | 现在怎么做 |
|---|---|
| 这次填错的字 | 点输入框右侧的 × |
| 下拉候选里的历史值 | 点字段标签旁的「管理」→ 勾选 → 合并到留空 → 清空（或填个规范名合并） |

× 保留，因为它解决的是另一件事；「管理」是新入口，落到的还是 v0.43 那块 `VocabPanel`，没有新接口、没有新数据表。
