# 5.52 · v0.55：AI 问答左右并排（左题目、右会话）

> 本文件是 [v0.54](v0.54.md) 之后的增量。用户贴了一张参考截图说「ai问答的时候能不能像这样左边是题目右边是ai」。

## 5.52.1 问题

v0.54 之前，点「让 AI 带我复习这道」之后整个详情区被换成会话：

```
if (ai) {
  return h(AiPane, { sessionId: ai.sessionId, title: ai.title, onBack: () => setAi(null) });
}
```

后果是**题面消失**。复习本来就是「看着题、自己先想一遍、再和 AI 对」，题面一没，学生只能凭记忆复述，也没法边看边写。而 AI 那边又看不到题 —— 它得靠 `mb_get` 现取，取回来的还是它自己那份。

## 5.52.2 改了什么

| 改动 | 位置 | 说明 |
|---|---|---|
| 详情主体提成变量 | `dsh-plugin/lib/client.js` 的 `DetailPane` | `return h('div.mb-detail', …)` 改成 `const body = h('div.mb-detail', …)`，其余一字未动 |
| 会话时左右并排 | 同上 | `ai` 有值就返回 `.mb-aiduo`：左 `.mb-aiduo-side` 装 `body`，右 `.mb-aiduo-main` 装 `AiPane` |
| 入口按钮收起 | 同上 | 会话已开时不再显示「让 AI 带我复习这道」（它只会再建一条会话） |
| 会话期间收起错题列表 | 同上（CSS） | `.mb-split:has(.mb-aiduo)` 把左栏宽度改成 1 栏并 `display:none` 掉 `.mb-left` |
| 接入中也显示标题 | `AiPane` | `!live || !SessionProvider` 分支补 `.mb-aititle` —— 右栏没有题面兜底，顶栏只剩一个「退出」太空 |
| 窄屏堆叠 | CSS `max-width:760px` | `.mb-aiduo` 变两行（题面 46% / 会话 54%），分隔线从右边改到底边 |

### 为什么用 `:has()` 收列表，而不是把 ai 状态提到 App

把 `ai` 提到 `MistakeBookApp` 也能做到「会话时只显示两栏」，但那是把 `DetailPane` 的 9 个 hook 顺序、渲染测试的 seed 契约、以及「详情被谁打开」的三种来源（列表 / 计划 / 学习）全部重排一遍。`:has()` 一行 CSS 就够，且**不支持时自动退化**成「列表 | 题目 | AI」三栏 —— 仍然能用，只是窄。窄屏那条媒体查询本来就已经把 `.mb-split` 压成一栏了，两边不冲突。

### 为什么左栏保留「这次记得怎么样」的评分卡

复习闭环的最后一步是给分。并排之后评分卡就在题面下面，学生看完 AI 的讲解可以顺手点「忘了 / 模糊 / 记得 / 简单」，不用退出会话再回去找。这是并排相对「整块替换」白捡的好处。

## 5.52.3 验证

| 用例 | 断言 |
|---|---|
| 渲染：AI 模式下两栏 | `.mb-aiduo` / `.mb-aiduo-side` / `.mb-aiduo-main` 都在；左栏有「题目 #6」与题干、**没有**「退出 AI」；右栏有「退出 AI」、会话标题与「正在接入会话…」 |
| 渲染：入口按钮收起 | 会话已开时整棵树里不再出现「让 AI 带我复习这道」 |
| 既有详情用例 | 未开会话时行为不变（答案折叠、四档评分、断点下拉、变式、历史、AI 入口） |
| 真实浏览器量尺寸（headless Edge + CDP） | 宽 504：两栏上下堆叠（题面 288 / 会话 338，正好 46/54）、`.mb-left` 计算值 `display:none`、`.mb-right` 不出现外层滚动条、对话区自己滚；`.mb-aiduo` 高度与 `.mb-right` 完全相等（627） |

结果：**195 个 python 测试 + 130 个 node 测试全绿**（node 从 129 增加到 130）。
