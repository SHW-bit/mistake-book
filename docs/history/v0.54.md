# 5.51 · v0.54：把 AI 从「单题」放到「今天」

> 本文件是 [v0.53](v0.53.md) 之后的增量。用户说「增加ai的权重,给出方案」，我清点了 AI 现在能介入的五个点，指出三个结构性缺口，给了一版 P1–P5 的方案；用户回「你看着做」，于是按我自己的建议做了 **P1 + P2 + P3**（三者串起来才闭环），路由形态选 **A**（新增一条路由，不动单题入口）。

## 5.51.1 三个结构性缺口

| # | 缺口 | 现场证据 | 后果 |
|---|---|---|---|
| A | AI 入口只有「单题」 | `dsh-plugin/lib/session.js` 的路由只认 `{ "id": <编号> }` | 今天有 8 道到期，得点 8 次、开 8 条会话；「让 AI 接管今天」这件事在界面上不存在 |
| B | 建议与动作断开 | 「今日建议」是 `h('div.mb-hrow', { key: item.id }, …)` 纯 div，没有 onClick | 面板告诉你「先练这几道」，然后你得自己去错题页找 —— 建议只是装饰 |
| C | AI 产出不回流 | `review_logs.student_answer / hints / judgement` 在 `client.js` 里 **0 处引用** | v0.51 花了力气存下来的判分依据，界面上一个字都看不到，用户不知道 AI 凭什么给这个档 |

## 5.51.2 改了什么

| 改动 | 位置 | 说明 |
|---|---|---|
| 抽出建会话的公共骨架 | `dsh-plugin/lib/session.js` | 新增 `createSession(deps, {title, kickoff})`，单题与批量共用；预设解析、模型选择、挂载、租约释放、改标题、注入一条都没复制 |
| 批量会话 | 同上 | `openBatchReviewSession(deps, {ids, notes})` + `titleForBatchSession()` + `kickoffBatchText()`；`BATCH_MAX = 30` |
| 新路由 | 同上 | `POST /api/mistake-book/session-batch`，`registerBatchSessionRoute()` 单独挂 |
| 批量入口 | `dsh-plugin/lib/client.js` | 计划页「今日建议」卡头「让 AI 带我练」、每一条建议可点、「今天 · N 道」卡头「让 AI 带我练今天」 |
| 会话占满内容区 | 同上 | App 新增 `aiSession` 状态；有会话时内容区换成 `AiPane`，页签仍在，切走即结束 |
| 判分可见 | 同上 | `HistoryBlock` 每条记录下挂一行证据：提示级数 / 我答 / AI 判断 |

### 为什么批量会话要抽公共骨架，而不是复制一份

建会话这段代码里有四件容易漏的事：`acquireScope` 给的租约是 `Symbol.asyncDispose`（不是 `release()`，漏还就让预设 revision 永远 collect 不掉）、`setup` 里 `mount` 必须先于别的 scoped 注册、`agentOptions` 必须自己带（宿主不会从 `meta` 补）、`meta.agentPreset` 是落盘字段。复制一份等于把这四个坑复制一份，而且以后改一个忘一个。抽出来之后，批量只负责「装哪几道题、叫什么标题、首条说什么」。

### 为什么批量路由是新开一条，而不是让原路由兼容 ids

单题入口是面板上最常用的按钮，`session.js` 又是整个插件里最容易出事的代码段（宿主服务、预设、租约三处都靠它）。新开一条路由的成本是十几行，代价是「批量出 bug 不会连累单题」。同理，批量只调 `loadMistake` 逐个读，读不到的题跳过并在剩下为零时报错 —— 一道题被删了不该让整轮复习开不起来。

### 为什么首条消息里仍然不给答案

单题版 v0.37 就把答案与解析从首条消息里拿掉了（先验信息进了上下文就拿不出去，叮嘱模型「别说」是软约束）。批量版沿用同一条纪律：只给题干、我上次答了什么、以及「为什么排这道」（来自简报的 reason），答案与解析一律等学生答完由 `mb_get` 现取。这条有测试用哨兵字符串钉着（`等价无穷小` / `正确答案` 都不许出现）。

### 为什么证据行放在复习历史里，而不是新开一页

留证是「这次怎么错的」的注脚，脱离那一次评分就没有意义。放在每条复习记录下面，翻历史时自然读到；单独做一页等于要求用户主动去查一个他不知道自己有的东西。

## 5.51.3 验证

| 用例 | 断言 |
|---|---|
| 批量标题 | 一道退回单题标题；多道写「错题复习 · 3 道」 |
| 批量首条 | 序号 / 题干 / 分类 / 理由齐全，且不含答案与解析 |
| 批量参数 | 缺 ids、空数组、全是非法值、超过 30 道，一律 `body-invalid` 且一次会话都不建 |
| 批量容错 | 读不到的题跳过，剩一道就退回单题标题；全读不到则 `mistake-unreadable` |
| 批量路由 | 只注册 `/api/mistake-book/session-batch`，与单题路径不同 |
| 计划页 AI 入口 | 「让 AI 带我练」传 `[5]` + `{5: '逾期 2 天'}`；「让 AI 带我练今天」传 `[5]` + `null`；没给 `onStartAi` 时不硬塞按钮 |
| 复习历史证据 | 提示级数 / 我答 / AI 判断都显示；`hints=-1` 且无留证的老记录不多出一行空证据 |

结果：**195 个 python 测试 + 129 个 node 测试全绿**（node 从 119 增加到 129）。
