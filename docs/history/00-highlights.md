# 错题本 · 版本速览

> 本文件是[错题本 README](../../README.md)的拆分文档。每个版本一句话，长文见同目录 v0.x 文件。

**v0.46（词表操作先算后写：合并/清空前先看影响几道题）**：v0.45 把「管理」入口放到了字段旁边，但点「删」是立刻写库的 —— 事后才告诉你「影响 N 道题」，而词表操作**没有撤销**（回收站只管整道题），删错一个值几十道题上的标签就没了。这一版三件事：**① 先算后写** —— `merge_knowledge()` / `merge_meta()` 各加 `dry` 参数，dry 跑同样的匹配但不写库、不 commit、不登记别名，返回 `moved` 与 `samples`（前 5 道题的题干），面板据此弹一条「将把 N 项并到『X』，影响 M 道题（如：求极限…）」的确认条，点「确认」才真写；**② 词表加搜索框** —— 值一多只能滚，现在即时过滤，且**只筛显示、不动已勾选的集合**；**③ 标签不再按空格切** —— `normalize()` 原来用 `re.split(r"[,，\s]+")`，「洛必达 法则」会被切成两个标签，现在只按逗号（含全角）与换行切，并去重。没有新接口：dry 是同一个 merge 函数的参数，保证预览与真执行走同一段逻辑。详见 5.43 节。
**v0.45（字段旁加「管理」：删下拉候选不用再翻菜单）**：v0.44 的 × 只清本次输入，用户指出要删的是**下拉候选里的历史值**。候选是从题库数据聚合出来的（`/api/meta` 的 facets），`<datalist>` 也不支持删条目 —— 唯一入口是「更多 ▾」→「词表整理」，在录入弹窗里想不到。这一版给学科 / 知识点 / 来源 / 标签四个字段标签旁各挂一个「管理」，点开复用同一块 `VocabPanel`（新增 `initialKind` 直接落到该档位），关闭后重拉 meta。× 保留。详见 5.42 节。
**v0.44（录入表单两处小修：知识点下拉分层、自由文本可清空）**：用户在录入弹窗里问「来源输入框，如果我不想要标签或点错了想删了怎么办」—— 两个问题叠在一起：知识点下拉是一串平铺值（录入用的是 `knowledge_flat`，而带层级的 `facetLabel()` 只用在筛选面板里），四个自由文本字段填错了只能全选退格。这一版只动 `client.js`：知识点 datalist 换成 facets（全角空格缩进 + 题量，写进输入框的仍是完整路径），学科 / 知识点 / 来源 / 标签四处加 × 一键清空（有内容才显示）。**没有新建知识点目录** —— `knowledge_tree` / `aliases` / `merge` / facets 四件套 v0.34 已有，缺的只是显示与清空。详见 5.41 节。
**v0.43（活词表：来源下拉不再越长越乱）**：v0.42 之后暴露的问题很具体 —— 录入弹窗的「来源」下拉里堆着 8 个内置值（作业 / 练习册 / 周测 / 月考 / 期中 / 期末 / 模拟考 / 其他），而 `meta()` 每次都把 `SOURCE_HINTS` 并回候选，**删不掉**；库里还有 `4` 这种手滑写进去的脏值；学科 / 知识点 / 标签同样只有裸 datalist，管理界面只做在已弃用的网页版里。这一版把「候选来自常量」改成「候选来自数据」：`_field_facets` 支持 `source`（带题量、按题量→最近用过→名字排序），0 题的内置值从下拉消失但仍留在 facets 里供管理面板的「未使用」分组；`merge_meta` 支持 `kind=source`，改名 / 合并 / 清空都走同一套；面板学习页新增「词表整理：来源 · 学科 · 知识点 · 标签」折叠面板（勾选 + 合并到 X / 清空）；录入时写了与已有值编辑距离 ≤1 的近似值，会在输入框下方提示「已有『期中』，用它更好」。`mb_suggest` / `mb_merge` 同步支持 `kind=source`。详见 5.40 节。
**v0.41（把 AI 能做的事扩到批量写、组卷、复盘与知识库整理）**：v0.21 起那 8 个工具，读的多、写的只有两件 —— 单题新增、单题判分。于是每次都要绕远路：一次录 20 道题得调 20 次 `mb_add`，想让 agent 出张卷子它够不着早就写好的 `/print`，「这周学得怎么样」只能自己拼五个接口，知识点里的脏值（`111`、`函数 单调性` vs `函数/单调性`）合并接口 v0.34 就有了却没人告诉 agent 该合哪些。这一版补 5 个工具，工具面从 8 个到 13 个：**`mb_batch`**（批量导入，默认 `preview:true` 只回显不写库，确认后再 `preview:false` 真入库）、**`mb_paper`**（组卷并直接给出可打印的 `/print` 链接）、**`mb_report`**（一份学习周报，一次拉齐 stats / analytics / mastery / plan / arena）、**`mb_suggest`**（查出近重复与无效值，只建议不改库）、**`mb_merge`**（执行合并，知识点 / 学科 / 标签三类都支持，`target` 留空 = 删除该值）。同一版还把面板录入弹窗的右栏收了：错因 / 来源 / 标签 / 难度 / 状态 / 错因描述全部折进「更多」，只留学科、知识点两个真正每次都要填的维度。详见 5.38 节。
**v0.40（插件升格为标准 DSH bundle：从「手抄补丁」到「可开关的插件」）**：v0.21 起，错题本插件是靠 `mklink /J` 建目录联接 + 把 `cordis.patch.yml` 里的 insert 块手抄进 profile 的 patch 文件挂上去的 —— 两步都只在本机成立，别人 clone 下来照做装不上；更糟的是 DSH 插件管理里**根本看不见它**，因为界面只认「在 `dependencies` 里 **且** 自己有 `dsh.bundle.patch`」的包，而 junction 形态的包也读不到（同目录另外八个插件全是真实目录，只有错题本是联接）。这一版把 `dsh-plugin` 做成和 `dsh-search-enhance` 同形态的标准 bundle：**① `package.json` 加 `dsh.bundle.patch`**（外加 `icon`/`files`/`engines`/`license`/`repository`，去掉 `private`）；**② 新增 `install.mjs`** —— 真副本安装（不建联接）、自动登记 `dependencies` 与 `dsh.profile.bundles`、把 patch 里的 `<REPO>` 替换成安装后的绝对路径，带 `--check` / `--uninstall`；**③ 补 `icon.png` / `README.md` / `LICENSE`**；**④ 删掉 profile `cordis.patch.yml` 里 3 个重复 insert 块** —— bundle 层与 profile 层是**叠加**不是覆盖，同一个 id 写两遍会 insert 两次。详见 5.37 节。
**v0.39（录入弹窗瘦身 + 下拉值可删）**：录入弹窗右栏原来是一条 7 行的垂直长龙（学科 / 难度 / 错因 / 来源 / 知识点 / 标签 / 试卷 / 状态 / 错因描述），最常用的只有学科和知识点，其余的每次都要划过去；而下拉里的脏值（学科写成「1」、知识点写成「111」）**只能合并、不能删**——想清掉一个错值，只能先把它并到另一个名字上，等于必须凭空造一个「垃圾桶」名字。这一版两件事：**① 右栏分两层** —— 第一层只放四个高频字段（学科 | 知识点 | 错因分类 | 状态），难度 / 来源 / 标签 / 试卷 / 错因描述收进「更多选项」折叠区，默认收起；**② 下拉值能删了** —— 学科和知识点输入框右边各加一个「管理」按钮，打开一个面板，勾选 + 留空 = 删除（题上的值清空、题本身不删），勾选 + 填规范名 = 合并，行尾 × 单个删除。删除走的是原来那个合并接口，只是 `target` 传空串，没有新增接口。详见 5.36 节。
**v0.38（AI 功能：把「别先看答案」从叮嘱变成机制）**：v0.37 只在会话首条消息上堵了泄题，但模型随时可以调 `mb_get` 把答案捞回来，而面板复习预设挂的那份 `dsh-plugin/skills/review/SKILL.md` 里还白纸黑字写着「必须先看正确答案与解析」——规则和实现第三次互相拆台。这一版做三件事：`mb_get` 默认**不返回**正确答案与解析（要看得显式传 `reveal: true`）；面板复习技能从头重写，跟代码对齐到 v0.37，顺势补上 `step` 断点、变式入库、`mb_weak_steps`、`kdeep`/`nokp`/`sort`；答疑预设改为显式 `reveal: true`（答疑本来就要看答案）。

**v0.37（复习链路四处漏水：首条消息就在泄题）**：v0.36 把变式链接上之后，我顺着「AI 带我复习」这条链路走了一遍，发现最贵的问题不在功能缺，在**规则和实现自相矛盾**：`SKILL.md` 写着「出题时不给答案，答案等学生答完再对」，可 `kickoffText()` 建会话时就把 `正确答案` 和 `解析` 直接摆进首条消息——模型很难忍住不说，提取练习当场作废。这一版四件事：**① 首条消息不再含答案** —— 只给题干、我的错答、错因、知识点、来源，末尾加一句「答案和解析我没贴在这里：等我答完，你用 `mb_get` 取」；需要时模型现取，那时学生已经答过了。**② 排序透到 agent 侧** —— `mb_due` / `mb_search` 加 `sort`（`created` / `due` / `stability` / `errors`），v0.35 建好的四档排序以前只有网页端能用到。**③ 知识点检索对齐网页端** —— `mb_search` 加 `kdeep`（默认含子树，跟 v0.34 的网页端一致）和 `nokp`（只看没归类的）；以前 agent 按父知识点搜是精确匹配，搜 `函数` 一条都出不来。**④ `mb_get` 列出已有变式** —— 以前 agent 拿到一道题看不见它攒过哪些变式，只能从 `mb_due` 行的「变式 N」猜，容易重复出同一道；现在直接列 `#41 求 lim… · 练过 2 次`，没变式就说一句怎么补。详见 5.34 节。
**v0.36（把变式题这条链路接给 agent）**：变式题的数据结构、去重、轮换、缺口排序早在 v0.10 就齐了，网页端也能增删练，但 **DSH 面板里那 8 个工具一条都用不上它** —— `mb_review` 只发 `{rating, step}`，后端 `_extract_variant()` 认的三个 `variant_*` 字段没有任何 agent 侧代码会发；`mb_due` / `mb_search` 的行也不带变式库存，agent 列到期题时看不出哪道该补题。这一版把三处接上：**① `mb_review` 透传变式** —— 参数表加 `variant_question` / `variant_answer` / `variant_knowledge`，判分和入库一次调用完成；只给答案不给题干会当场拒绝（不发请求）。**② 回执说清去重结果** —— 「已存变式：#41」/「变式已在库中：#41（复用，已计一次练习）」；提交了题干却没回执时明确报「变式未入库」，绝不静默成功。**③ 列表行带库存** —— `brief()` 输出 `#12 [高数] 求极限（复习中 · 无变式）`，`无变式` 就是该补的题；老接口没这个字段时不会瞎猜。顺手修了个真 bug：`mb_add` 不传难度时以前塞 `difficulty: 0`，而服务端只收 1-5，**导致「不填难度就录不进去」**——现在不传就不发这个字段。`SKILL.md` 的阶段 3 / 阶段 4 也从「只说 `python mb.py`」改成面板工具与 CLI 两套写法。详见 5.33 节。

**v0.35（列表排序器 + 学科标签合并 + 弹窗内翻页）**：三件用久了会烦的小事。**① 列表排序** —— 以前只能按录入时间倒序，「最该先复习的」「错得最多的」只能自己翻。现在 `?sort=` 有四档：`created`（最新录入，默认）/ `due`（最快到期，没排期的沉底）/ `stability`（最不稳定）/ `errors`（错得最多）。档位是白名单常量 `SORT_OPTIONS`，不是把 URL 里的串拼进 `ORDER BY`（那是注入口子）；非法值静默落回 `created`，并把实际生效档回传，前端下拉才不会选中一个不存在的项。网页端「最新录入 ▾」在搜索框右边，只影响顺序、不进筛选 chips、不参与「重置」。**② 学科与标签的脏值合并** —— v0.34 只收拾了知识点，`学科` 里还躺着 `1`、`未分类`，`标签` 里躺着 `4`。学习页合并面板加了类型选择（知识点 / 学科 / 标签），后两者走新的 `POST /api/meta/merge`：`_field_facets()` 给两边都算「值 + 题数」，合并时整列改写。标签是逗号分隔的扁平值，必须先 `LIKE '%x%'` 粗筛**再精确比对**（否则 `4` 会命中 `14`，有专门的回归测试钉住）。知识点是 `/` 分层要拼后缀、学科标签是整列改写，所以没硬塞进同一个函数。**③ 弹窗内翻页** —— 复习完一道要退出去再点下一道，中间那步很烦。现在弹窗底部有「‹ 上一题 / 下一题 ›」，按**当前列表顺序**在本页内翻，到头自动置灰；跨页不翻。顺手修了 `stability` 排序的一个真 bug：`fsrs_stability = 0`（从没复习过）被排在最前，让这一档实际等于「最新录入」的同义词 —— 现在未复习的整组沉到后面。

**v0.34（知识点分层检索 + 合并清理）**：以前「知识点」是一个自由文本框，谁都能往里写 `111`、`2` 这种脏值；下拉里是一长串平铺的原字符串，点父节点 `函数` 一道题都搜不到（默认精确匹配）；树视图和别名机制早就写好了，却没人用得上。这一版把三条链路接上：**① 存的时候给台阶** —— 表单输入框挂上 `datalist`，历史路径带 `/` 层级直接补全，placeholder 写着「如 函数/单调性（用 / 分层）」；**② 找的时候分层** —— `/api/meta` 的 `knowledge` 从字符串数组升级成 `[{path,name,parent,depth,count}]` facet（保留 `knowledge_flat` 兼容老调用方），下拉按 `depth` 用全角空格缩进并带题数，点父节点默认连子树一起搜（`kdeep=1`），另加「（未归类 · N 道）」项走 `nokp=1`；**③ 乱的时候能收** —— 学习页新增「合并 / 清理知识点」面板，勾几个脏值 + 填一个规范名，一次 `POST /api/knowledge/merge` 把题批量改写过去并顺手登记别名，子树层级会保留（`函数/二次函数` 并到 `初中数学` → `初中数学/二次函数`）。CLI 侧同步加了 `mb.py merge --to`、`list --kq`（前缀包含）/`--exact`（精确）/`--nokp`（只看未归类），`merge` 也纳入 `--read-only` 拦截名单。

**v0.33（学习 / 计划 / 分析三页重做：先给结论，再给按钮）**：这三页以前是「数据墙」—— 一屏十几个数字和图表，看完不知道该干什么。这一版按 Anki / SuperMemo 的成熟范式重排：**顶部一张结论卡**（一句人话说清「你现在什么状况」+ 一个主按钮）、**中间一排 KPI**、**下面才是可折叠的明细**。学习页的结论是「今天先补「X」」+「先练「X」· N 道」，点按钮带着知识点筛到错题页；计划页是「今天有 N 道要复习（其中 M 道已逾期），大约 X 分钟」+「开始今天的 N 道」，加一条 7 天负载柱；分析页是「最该补「X」」+「去练「X」· N 道」。明细（知识点树、保持度、错因分布、趋势图）全部收进 `details` 折叠块，默认不开。面板与网页端同步改，详见 5.30 节。

**v0.32（详情页重做 + 图片加载修复）**：两件事。**详情页**从平铺的 `.mb-block` 改成卡片体系（`.mb-card` / `.mb-cardhead` / `.mb-attr` / `.mb-facts`），题目卡带 accent 描边、属性收成三行虚线分隔、「看答案与解析」和「让 AI 带我复习这道」都成整宽主按钮、评分条限宽 560px。**图片**修了两个 bug：面板代理把二进制当文本解码（`res.text()`）导致全是坏图，以及详情页把四张图不分 `field` 全塞进「题目」卡 —— 现在图片按 `field` 回到题目 / 我的答案 / 正确答案 / 解析各自的位置，并改走 JSON 里的 data URL（Pillow 缩到 1000px，1.3MB 截图 → 98KB），刷新页面即生效，不用重启 DSH。另外补上**点图放大**：详情页和录入表单里的缩略图点一下就进全屏浮层（Esc / 点背景 / 点 × 关闭），面板与网页端都有。

**v0.27（面板视觉全部重做）**：DSH 面板从 v0.21 起视觉一直沿用网页版 v0.16 的那套「13px + 6px 圆角」体系，塞在 DSH 侧栏里偏灰、层级糊、弹窗在深色主题下还会白底浅字。这一版把面板的样式层整块重写：颜色全部走 `color-mix(in srgb, currentColor …)` 从宿主文字色推导（自动跟随任意主题）、页签改成可横滑的 pill 条、列表行左侧画 3px 状态轨、评分按钮按档位染色、弹窗显式给底色并单独覆盖深色、头部拆成「标题 + 计数 + 新建」与「页签」两行。**只改样式与头部结构，组件 DOM、类名与交互逻辑一行没动**，详见 5.24 节。

**v0.28（按视觉复核收紧）**：v0.27 是盲改的。这一版把 vision 链路打通，用真实渲染截图复核、再用 CDP 量数值，按数据改了七处：列表行把三个操作按钮挪进行内浮层（一屏 3~4 题 → 6 题）、头部三层各收一档（占高 12.7%）、次要文字对比度提到 AA、「看答案与解析」升为主按钮、宽屏左栏从固定 320px 改成 `clamp(300px,32%,420px)`、深色主题新增 `--mb-surface` 令牌。**没有改任何测试断言**，详见 5.25 节。

**v0.29（错题卡片 + 录入表单重做，图片导入）**：这一版动的是两块最常看的界面。**列表卡片**把学科 / 知识点 / 错因 / 复习次数收成一行 17px 的小标签（`white-space:nowrap` + 省略号，到期徽章排最前、窄屏被裁时最后才丢），缩略图放大到 50px 圆角方块并让出右上角，三个操作按钮移到右下角、行间加发丝分隔线 —— 单行从 85px 降到 **72px**，一屏能多看一题。**录入表单**按参考 App 的观感改成左右两栏：左栏「题目 / 我的错误答案 / 正确答案 / 解析」四块各带一道 3px 竖条（题目淡蓝、错答橙、正解绿），右栏八个小字段，底栏吸底。**图片导入**补齐三条路径 —— 拖入文件、点击选择、截图后 Ctrl+V，支持一次多张（每张 ≤8MB），走的是 v0.20 就有的 `mistake_images` 多图表，数据库一行没改。详见 5.26 节。

**v0.30（三块图片导入 + 紧凑按钮 + 新建浮层）**：v0.29 的表单只有一个图片入口，挂在「题目」块下面，占了一整块拖拽区的高度。这一版把图片**按块归属**：题目 / 我的错误答案 / 正确答案 / 解析四块各有一个 22px 高的「＋ 图片」小按钮，点它只给本块选图，缩略图 56px 贴在块内文本下方、可单张删除；省下来的高度全给了文本区（题目 4→6 行、其余 3→5 行，字号 13.5px、行高 1.62）。三条导入路径一条没少 —— 按钮点选、拖文件到任意块（该块虚线高亮）、截图 Ctrl+V（粘到光标所在块），全部复用 v0.20 的 `mistake_images` 表，只加了一列 `field`。**新建**改成整页视图 —— 和「学习」「计划」同一个层级（`.mb-detail` 页），顶部「← 返回错题」，不再走弹窗。详见 5.27 节。

**v0.31（图片上限 2MB → 8MB）**：v0.30 之后反馈「手机拍的照片导不进去」——2MB 只够截图，手机原图普遍 3~8MB。这一版把四道上限一起抬：单张解码后 8MB、单张 Data URL 11.2M 字符、请求体 64MB（6 张 8MB 图 base64 后仍够）、前端 addFile 与网页版 useImageFile 的校验同步到 8MB。实测 5MB 图 201 通过、9MB 图 400 拒绝。详见 5.28 节。

v0.3 换掉了固定复习阶梯，改用 **FSRS-6**（Anki 现用的开源记忆调度算法），并提供 `mb.py` 命令行 + [SKILL.md](../../SKILL.md)，让 DSH 里的 AI agent 能直接驱动「取题 → 出变式 → 判分 → 回写」。
