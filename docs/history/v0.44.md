# 5.41 录入表单的两处小修：知识点下拉分层、自由文本可一键清空（v0.44）

> 本文件是[错题本 README](../../README.md)的拆分文档。含 5.41 节。上一版见 [v0.43.md](v0.43.md)。

## 5.41.1 问题：都在录入弹窗里

用户问的原话是「来源输入框，如果我不想要标签或点错了想删了怎么办」。查下来是两件事：

| # | 现象 | 根因 |
|---|---|---|
| 1 | 知识点下拉是一长串平铺值，看不出谁是谁的子节点 | 录入表单的 `choices('mb-dl-knowledge', ...)` 用的是 `meta.knowledge_flat`（裸字符串数组）；带层级的 `facetLabel()` 早就有了，只用在筛选面板的下拉里 |
| 2 | 学科 / 知识点 / 来源 / 标签填错了只能全选退格 | 四个都是普通 `<input>`，没有清空操作；`<datalist>` 本身也不提供删除条目 |

## 5.41.2 改了什么

| 位置 | 改动 | 量 |
|---|---|---|
| `dsh-plugin/lib/client.js` | 知识点 datalist 改用 `knowledgeFacets(meta).map(f => ({ value: f.path, label: facetLabel(f) }))` —— 显示带全角空格缩进与题量，写进输入框的仍是完整路径 | 1 行 |
| `dsh-plugin/lib/client.js` | 新增 `clearable(key, extra)`：把 `<input>` 包进 `.mb-clear`，有内容时右侧浮一个 × ，点了清空；学科 / 知识点 / 来源 / 标签四处全换上 | ~20 行 |
| `dsh-plugin/lib/client.js` | CSS 三条：`.mb-clear` / `.mb-clear>input` / `.mb-clear-x` | 3 行 |

没有新增接口、没有动数据模型 —— 复用的是 v0.34 的 `knowledgeFacets` / `facetLabel` 与 v0.43 的 `choices({ value, label })`。

## 5.41.3 为什么不做「知识点目录」

同期看了 GitHub 上几个同类项目（error-notebook / MistakeNotebook / ai-wrong-notebook），它们共同的强项是「知识点从内置目录里选，AI 只能在目录内打标」，脏值进不来。但那份目录对我们是**重复建设**：`knowledge_tree()` / `knowledge_aliases` / `/api/knowledge/merge` / `meta().knowledge` facets 四件套 v0.34 就有了，缺的只是「没人往里填」和「填的时候看不出层级」。所以这一版只补显示与清空，不新建目录。
